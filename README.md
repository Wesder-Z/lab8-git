## Идея приложения

Приложение принимает вопрос студента через CLI и отправляет его внешнему ИИ
API. Подготовка запроса находится в `service.py`, сетевой клиент находится в
`ai_client.py`, а запуск из командной строки описан в `cli.py`. Благодаря этому
логику можно тестировать без ключа API и без сетевого вызова.

## Установка через Poetry

Требуется Python 3.10 или новее и установленный Poetry:

```powershell
poetry install
```

После установки можно проверить CLI без отправки запроса:

```powershell
poetry run study-assistant --help
```

## OpenAI API

Ключ не хранится в исходниках. Перед рабочим запуском задайте переменные
окружения:

```powershell
$env:OPENAI_API_KEY = "ваш_ключ"
$env:OPENAI_MODEL = "gpt-5.5"
poetry run study-assistant "Объясни разницу между списком и кортежем в Python"
```

Клиент использует `OpenAI.responses.create()` и читает результат из
`response.output_text`. При отсутствии ключа, ошибке сети или пустом ответе
пользователь получает понятное сообщение, а не трассировку исключения.

## Docker

Сборка и запуск выполняются так:

```powershell
docker build -t lab8-ai-assistant .
docker run --rm -e OPENAI_API_KEY="$env:OPENAI_API_KEY" lab8-ai-assistant
```

Образ запускает справку CLI. Для рабочего запроса команду контейнера можно
переопределить аргументами запуска.
